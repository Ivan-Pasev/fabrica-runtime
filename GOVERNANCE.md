# Governance

Fabrica Runtime is an open-source project in the Fabrica / Digital Fabrica product family.

## Principles

1. Working-first evolution.
2. Explicit provenance.
3. No false authorship.
4. Backward-compatible refabrication where practical.
5. Public architectural decisions should be inspectable.
6. Security and correctness take precedence over cosmetic renaming.

Substantial changes should document intent, compatibility impact, affected invariants, verification, and provenance implications.
