# Contributing to Fabrica Runtime

Thank you for contributing.

## Expectations

- Keep the repository installable and testable.
- Preserve Apache-2.0 and upstream attribution requirements.
- Do not remove provenance notices.
- Prefer focused changes over global renames.
- Add or update tests for behavior changes.

## Local setup

Create a Python virtual environment, install the package in editable mode, install pytest, and run the test suite before submitting a pull request.

Pull requests should explain what changed, why, compatibility impact, verification performed, and whether lineage/provenance is affected.
